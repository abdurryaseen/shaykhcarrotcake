# Shaykh Carrot Cake

Website for Shaykh Carrot Cake, a local carrot cake business in Detroit, Michigan.

Plain static site (HTML/CSS/JS), no build step — ready for GitHub Pages.

- `index.html` — the page
- `assets/site.css` — styles
- `script.js` — small scripts

To preview locally, open `index.html` in a browser.

Bracketed text like `[phone number]` marks placeholders to replace with real business details.
For a custom domain, add a `CNAME` file with the domain name.
